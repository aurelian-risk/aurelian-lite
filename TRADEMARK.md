# The Aurelian name and mark

The Mozilla Public License covers the code in this repository. It does not cover the
name, the wordmark or the logo — no software licence does. This page says what is fine
without asking.

## Fine, no permission needed

- Saying your work is **based on**, **derived from**, **built with** or **compatible with**
  Aurelian Lite.
- Naming Aurelian Lite in documentation, articles, talks, comparisons and reviews,
  favourable or not.
- Keeping the name and the mark in an unmodified build you pass on. That is the point of
  them.
- Linking to this repository and to aurelian-risk.com.

## Please ask first

- Calling your own product, fork, service or company **Aurelian**, or a name close enough
  to be mistaken for it.
- Using the mark as the icon or logo of something that is not this project.
- Anything that reads as if this project produced, endorsed or supports your work.

## Modified builds

A fork is welcome — that is what the licence is for. What a fork should not do is present
itself as this project. Rename it, and say what it is derived from. Concretely: change the
product name in `src/profile/*/product.ts`, and keep the source reference in the built
file pointing at wherever your source actually is.
